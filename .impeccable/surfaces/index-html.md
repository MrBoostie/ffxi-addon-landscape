# Surface: GitHub Pages catalog (index.html)

Mode: operate. Players browsing on a second monitor or alt-tabbed out of the game, picking Windower addons to install. Job: find an addon that fits a need (a job, a piece of content, a playstyle), learn what it does, reach its repo. Must keep: the three starter packs, description source links with confidence, research/method links. Single static HTML fetching `ffxi-addon-catalog-normalized.json`. Not affiliated with Square Enix or Windower; no game art or logos.

## Direction contract

THESIS: The catalog is a menu inside Vana'diel: the player navigates it the way they navigate the game's own windows, with a cursor that lands on one addon and a help window that explains it. Refuses the category default of a flat dark table with tag pills.

OWN-WORLD: Night-navy ground (#060a1c); translucent blue window panels (top-lit blue gradient, 1px periwinkle frame, faint inner highlight, 8px radius); white text, pale-blue secondary, gold (#ffe08a) for window titles and the selected line; categories carry the eight elemental crystal colours as small faceted crystal marks; M PLUS Rounded 1c throughout.

STORY: The visitor searches or picks a category, scans a dense list of names with update date and stars, lands the cursor on one, reads the help window (what it does, risk note, where to get it, source and confidence), and opens the repo. Starter sets offer a shortcut; research links sit in their own small window.

FIRST VIEWPORT: Title window across the top (name, counts, search field at right). Below, three windows side by side: Categories (left, ~270px), Addons list (centre, dominant; its head holds the title with a live count, and the Updated and Sort controls on a fixed second row so the head never reflows while typing), Help (right, ~380px) showing the selected addon. Signature move: the white pointing-hand cursor beside the selected category and the selected addon, bobbing gently, moving with arrow keys.

FORM: the pick card (my top-ranked grounded candidate, #1 of seven: FFXI's in-game menu windows), chosen over the assigned strategy-guide direction. seed:b9ba7e015cfdf786

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
